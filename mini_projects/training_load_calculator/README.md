# Training Load Calculator

## Specification

## Pseudocode

START

Ask the user for workout duration.

Ask the user for perceived exertion.

Convert both answers into numbers.

Multiply duration by exertion.

Display a session summary and the training load.

END

1. Inputs: workout duration in minutes and perceived exertion from 1 to 10.
2. Conversions: convert the user's typed responses into numbers.
3. Calculation: multiply duration by perceived exertion to calculate session load.
4. Output: display the duration, exertion, and calculated session load.
5. Non-goals: no interface, database, charts, permanent storage, or advanced validation.
